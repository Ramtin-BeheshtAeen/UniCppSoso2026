# Probeklausur C++ (90 Minuten)

Drei Aufgaben, jede in einem eigenen Ordner mit eigenem Makefile.

    cd aufgabe1
    make          # kompiliert (bei Aufgabe 1 und 3 wird danach auch ausgeführt: make run)

Wichtig (wie in der echten Klausur): `make` ohne Fehler bedeutet nur,
dass der Code syntaktisch korrekt ist, NICHT, dass die Aufgabe richtig gelöst ist.

| Aufgabe | Thema                                   | Punkte | Zeitvorschlag |
|---------|-----------------------------------------|--------|---------------|
| 1       | Syntax: Programm reparieren, Pointer    | 20     | 15 min        |
| 2       | Datentypen + Deklarationen (KEINE Implementierung) | 25 | 20 min |
| 3       | Programmieraufgabe: Klassen + STL       | 55     | 55 min        |

Die Aufgabenstellung steht jeweils oben in der .cpp/.h-Datei als Kommentar.

Erst selbst lösen, dann in der separaten Datei probeklausur_loesung.zip nachschauen!
Dort kannst du `make check` ausführen (Aufgabe 2 prüft dort deine
Signaturen automatisch, wenn du deine Datei hineinkopierst).
